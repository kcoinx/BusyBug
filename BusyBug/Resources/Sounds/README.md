# BusyBug Sound Assets

These five WAV effects were generated specifically for BusyBug from simple
synthesized sine tones. They are original project assets and have no external
licensing or attribution requirements.

The files are intentionally mono, short, and low-amplitude:

- `button_tap.wav`
- `mission_complete.wav`
- `bug_discovered.wav`
- `sticker_earned.wav`
- `celebration.wav`

Runtime playback volume is reduced further by `SoundManager`.
